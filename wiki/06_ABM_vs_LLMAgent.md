# 06. 傳統 ABM 代理人 vs. 現代 LLM Agent 邊界探討 (Traditional ABM vs. LLM Agent)

## 邊界界定原則 (Boundary Principles)
在進行計算社會科學與複雜系統探討時，必須嚴格釐清「傳統 ABM 代理人」與「現代大型語言模型驅動之 LLM Agent」的範式邊界 [Source 1]：

- **傳統 ABM 代理人**：
  - 核心為**極簡的數學或邏輯啟發式規則（Heuristic Rules / FSM）** [Source 1]。
  - 不具備自然語言交談能力、不具備開放世界的常識推理，更不會自主思考 [Source 1]。
  - 追求的是「極簡個體 $\to$ 豐富湧現」的簡約之美 [Source 1]。
- **現代 LLM Agent**：
  - 以大型神經語言模型（如 GPT-4）為大腦，具備語言理解、思維鏈推理與工具調用。
  - *(更多深入對比分析隨後續文獻逐步擴充)*


## 決策維度對照：以謝林模型為例
- **傳統謝林 Agent**：僅包含一個數值條件判斷 `if same_ratio < T: move()`，沒有自然語言理解、沒有情感分析、沒有長期心智歷程 [Source 2]。
- **現代 LLM Agent**：如果用現代 LLM 模擬居民，居民會以自然語言表達文化認同、交談協商、甚至寫信給房東，兩者複雜度處於完全不同的抽象層級 [Source 2]。


## 湧現層次的比較
- **傳統 ABM 的湧現**：來自於**大量簡單數值規則個體**在物理/空間網格上的互動（如 Boids 鳥群隊形、謝林隔離斑圖）[Source 3]。
- **現代 LLM Agent 的湧現**：不僅有空間湧現，更展現出**語言與語意層次的認知湧現**（如常識推理、意圖揣摩、自發協商）[Source 3]。


## 異質性表現維度的飛躍
- **傳統 ABM 的異質性**：體現在「靜態數值參數」（如 Sugarscape 中 Vision=3 或 Metabolism=2、謝林模型中門檻 $T=30\%$）[Source 4]。
- **現代 LLM Agent 的異質性**：體現在「全自然語言的人設（Persona）與生活記憶」（如心理創傷、職業抱負、說話口吻），創造出具有深層認知多樣性的虛擬個體 [Source 4]。

## 傳統 ABM 代理人 vs. 現代 LLM Agent 全維度對比

| 比較維度 | 傳統 ABM 代理人 (Traditional Agent) | 現代 LLM Agent (如 AutoGPT, MetaGPT) |
| :--- | :--- | :--- |
| **心智與決策核心** | **極簡規則與有限狀態機 (Heuristic / FSM)**：如 `if neighbors < T: move()` [Source 5] | **大語言模型大腦 (LLM Brain)**：具備全域常識、思維鏈 (CoT) 與自然語言推理 [Source 5] |
| **語言理解與交流** | 無語言能力，僅能傳遞離散數值或狀態標籤 [Source 5] | 具備完整自然語言理解、八卦討論、政策協商與情書撰寫能力 [Source 5] |
| **研究目標追求** | **以極簡微觀規則湧現出宏觀複雜秩序**（越簡單越美）[Source 5] | **以強大認知能力自主解決複雜工程任務**（如寫軟體、自動化瀏覽）[Source 5] |
| **環境感知與工具** | 僅感知局部相鄰網格或網路節點狀態 [Source 5] | 調用外部 API、計算機、搜尋引擎與程式碼直譯器 [Source 5] |
| **兩者融合新範式** | **生成式社會模擬 (Generative Agents)**：將 LLM 作為傳統 ABM 的大腦，突破傳統二元網格限制，開啟擬真人性社會模擬之新紀元 [Source 5] | 融合 ABM 的多代理人環境，模擬市場、社群同溫層與政治衝突 [Source 5] |

> [!CAUTION] 邊界紅線警示
> 在教學與學術研究中，絕不可將現代 LLM Agent（如 AutoGPT）的「工具調用、自主代碼生成」等概念混淆為傳統 ABM 的基本定義。傳統 ABM 是以極簡啟發式規則為榮的計算社會科學學派！[Source 5]
