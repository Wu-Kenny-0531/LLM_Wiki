# 06. 傳統 ABM 代理人 vs. 現代 LLM Agent 邊界探討 (Traditional ABM vs. LLM Agent)

## 邊界界定原則 (Boundary Principles)
在進行計算社會科學與複雜系統探討時，必須嚴格釐清「傳統 ABM 代理人」與「現代大型語言模型驅動之 LLM Agent」的範式邊界 [Source 1]：

- **傳統 ABM 代理人**：
  - 核心為**極簡的數學或邏輯啟發式規則（Heuristic Rules / FSM）** [Source 1]。
  - 不具備自然語言交談能力、不具備開放世界的常識推理，更不會自主思考 [Source 1]。
  - 追求的是「極簡個體 $\to$ 豐富湧現」的簡約之美 [Source 1]。
- **現代 LLM Agent**：
  - 以大型神經語言模型（如 GPT-4）為大腦，具備語言理解、思維鏈推理與工具調用。
