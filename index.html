Lecture 02 • Paradigm Shift

為什麼傳統宏觀公式無法看懂真實社會？

2008 年金融海嘯中，少數邊緣機構的違約引爆了全球崩盤，傳統代表性方程式模型對此束手無策。

傳統方程式模型的盲點
虛幻的「同質全知理性人」假設
• 代表性個體：假設社會是由一群完全一樣的「平均人」構成，抹殺了真實世界的個體差異。
• 超理性運算：假設每個人都能算遍全宇宙求得「全局最優解」，無視人類心智與資訊的局限。
• 均勻混合 (Well-mixed)：忽視人際地理與社交網絡的剛性空間限制。
ABM 的現實主義解法
有限理性與「滿意化」原則
• 生活生動比喻（買早餐）：我們買早餐不會算遍全台北每家店的 CP 值極值；只要樓下三明治「夠好吃且不用排隊」，決策立刻終止（Satisficing 原則）。
• 擁抱異質性：在 ABM 中，世界上不存在兩個一模一樣的人，每個人擁有不同的偏好與人脈。
• 局部視野：代理人僅觀察身邊鄰近動靜，資訊透過時間空間逐步擴散。
Lecture 03 • Architecture

積木遊戲：ABM 核心三要素

就像玩《模擬市民》或大富翁，整個計算世界由三塊基石拼裝而成：代理人、環境與互動機制。

微觀主角
1. 代理人 (Agent)
具有自主意識的運作單元：
• 內部狀態：位置座標、財富、健康、門檻偏好。
• 決策規則：如「若同族鄰居不足則搬家」的啟發式邏輯。
時空舞台
2. 環境 (Environment)
代理人生存的空間媒介：
• 空間型態：離散網格棋盤（Lattice）、連續物理幾何空間、或抽象社群網路拓撲。
• 動態資源：資源生長、障礙物阻隔。
網絡連結
3. 互動 (Interaction)
個體與環境及鄰里的通訊：
• 在地性原則：代理人僅能與其視野內（Moore 鄰域 8 格）的鄰居互動。
• 回饋機制：個體決策改變局部，漣漪疊加為宏觀。

Lecture 05 • Core Magic

複雜系統的靈魂：什麼是「湧現」？

整體大於部分之和：宏觀結構既不存在於單一個體內，也無法由個體簡單線性相加得出。

🌊 1. 水分子與漩渦
單個水分子只有 H₂O 化學結構，完全沒有「潮濕」或「漩渦」的性質；但數億個水分子相互碰撞流動時，自然湧現出壯觀的漩渦與海浪。
🧠 2. 神經元與大腦意識
單個神經細胞只有簡單的電位脈衝與突觸傳遞；但數百億個神經元交織成網絡，便湧現出思想、記憶、情緒與人類意識。
🦅 3. 鳥群飛翔 (Boids)
沒有任何「隊長鳥」指揮，每隻鳥只需遵守「不撞同伴、對齊速度、靠攏群聚」三條極簡規則，便自發湧現出空中整齊曼妙的避障編隊。
Lecture 06 • Dynamics

非線性反饋與個體多樣性的力量

打破線性直覺：為什麼在複雜系統中，微小的火花會引爆天翻地覆的連鎖雪崩？

非線性 (Non-linearity)
臨界點 (Tipping Points) 與蝴蝶效應
• 非正比關係：投入兩倍努力不等於獲得兩倍產出。
• 生活生動比喻（森林大火）：幾百個微小火星可能被自然撲滅，看似風平浪靜；但一旦乾燥度跨過臨界門檻，下一個微小火星會瞬間引爆整座森林大火！
• 正回饋循環：恐慌性拋售與謝林搬家骨牌效應，迅速將系統推向極化。
異質性 (Heterogeneity)
多樣性是系統具備抗脆弱性的源泉
• 生活生動比喻（股市生態）：如果市場上每個人都是同質的「理性複製人」，一旦有利空所有人同一微秒搶著賣，市場瞬間猝死；正因為有人看空、有人貪婪逢低承接，分歧才促成了交易與流動性。
• Sugarscape 糖原模型：代理人天生的視力與代謝率差異，在無人為干預下自然湧現出貧富不平等的帕雷托分佈。
Lecture 07 • Frontier Boundaries

極簡規則個體 vs. 語言智慧大腦：嚴格邊界

在學術與教學中，切勿將傳統 ABM 代理人與現代 LLM Agent（如 AutoGPT）混為一談！

傳統 ABM 代理人 (如謝林模型)
極簡規則為榮 (Heuristic Rules)
• 決策核心：簡潔的數學或邏輯判斷 if ratio < T: move()。
• 能力特徵：不會說話、沒有常識、不能調用工具，更不會思考。
• 學術追求：個體越簡單，湧現出的宏觀結構越複雜，模型就越偉大。
現代 LLM Agent (如 AutoGPT, MetaGPT)
通用認知與工具執行
• 決策核心：以大語言模型（如 GPT-4）為大腦，具備思維鏈 (CoT)。
• 能力特徵：流暢的自然語言理解、工具調用、長期記憶檢索。
• 學術追求：利用強大心智自主完成複雜工程任務。
• 現代融合：生成式代理人（Generative Agents）正在將 LLM 作為大腦注入傳統 ABM，開啟社會模擬新紀元。
