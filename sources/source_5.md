# [Source 5] ABM vs. 傳統方程式模型，以及傳統 ABM 與現代 LLM Agent 的本質邊界

## 1. ABM vs. 傳統方程式模型 (Equation-Based Models, EBM)
在科學計算與社會模擬中，傳統方法長期依賴方程式模型（如常微分方程組 ODE、差分方程、系統動力學 System Dynamics 或多變量計量回歸）：

| 比較維度 | 傳統方程式模型 (EBM, 如微分方程/宏觀經濟模型) | 代理人基模型 (ABM, 如謝林模型/糖原模型) |
| :--- | :--- | :--- |
| **建模起點** | **自頂向下 (Top-down)**：直接對宏觀聚合變量（如總GDP、感染率 $I(t)$）建立連續方程 | **自底向上 (Bottom-up)**：對每個獨立微觀個體的行為規則與交互進行編程 |
| **個體假設** | 假設個體同質化（Homogeneous）、或以平均代表性個體計算 | 充分體現個體異質性（不同年齡、偏好、網絡連線） |
| **空間與拓撲** | 通常假設「完美混合（Well-mixed）」或無空間維度 | 具備精確的空間幾何網格（Lattice）或複雜社交網路拓撲 |
| **因果推導機制** | 方程式給出變量間的相關或宏觀約束，但難以解釋「如何從個體行為發生」 | 自然揭示宏觀現象「如何經由微觀互動一步步演繹湧現（Generative explanation）」 |
| **非線性與突變** | 難以處理不連續的相變（Phase transitions）與路徑依賴 | 天然擅長捕捉臨界爆發點、骨牌連鎖效應與回饋循環 |

## 2. 重要邊界劃分：傳統 ABM 代理人 vs. 現代 LLM Agent
在現代人工智慧蓬勃發展下，必須特別釐清**「傳統 ABM 中的代理人」**與**「以大語言模型驅動的現代 LLM Agent（如 AutoGPT, MetaGPT）」**之間的嚴格學術邊界：

1. **決策機制的根本差異**：
   - **傳統 ABM Agent**：決策本質是**「簡單數學/邏輯規則（Heuristic Rules / FSM）」**。例如謝林模型中的「如果同類鄰居小於 30% 則搬家」。傳統 Agent **不具備常識推理、沒有自然語言理解能力，也不會思考**，其強大之處在於用數千個「極簡規則個體」展現出宏觀結構。
   - **現代 LLM Agent**：以大型預訓練語言模型（如 GPT-4）為大腦，具備龐大的全域常識、思維鏈（CoT）推理、目標分解、工具調用（Tool Use）與多模態感知能力。
2. **研究焦點的差異**：
   - **傳統 ABM**：關注的是「微觀簡單規則如何自組織湧現（Emergence）出複雜宏觀模式」，個體越簡單、能湧現出越複雜的現象，模型就越優雅。
   - **現代單體 LLM Agent（如 AutoGPT）**：關注的是「單一代理人如何利用外部工具、長期記憶與計畫分解來替人類解決複雜工程任務（如寫代碼、自動訂票）」。
3. **兩者的現代融合趨勢**：
   - 近年來學術界開始將 LLM 作為傳統 ABM 代理人的認知核心（即生成式代理人 Generative Agents），讓虛擬社會模擬突破過去「只能處理二元移動或簡單數值」的局限，進入能夠模擬文化擴散、八卦流傳與政治協商的全新紀元。但在分析傳統 ABM 理論時，絕不可倒果為因，將現代 LLM Agent 的複雜定義混入傳統 ABM 的基礎框架中。
